# DT207G - Programmering i TypeScript
## Lab 3, Angular I

Repot innehåller en webbplats med en konverterare för meter till fot, celsius till fahrenheit och vice versa. [Testa konverteraren här](https://dt207gunits.netlify.app/convert).

Webbplatsen använder ramverket Angular och bygger därav på komponenter. Varje sida för webbplatsen har en egen komponent under src/app/pages. Komponenter som läggs in under olika sidor, såsom navigering, ligger under src/app/partials. För styling används CSS.
